# Security policy

Não reporte vulnerabilidades, chaves expostas ou possíveis violações de dados
em issues públicas. Use a aba **Security** do repositório para criar um
relatório privado ou contate o mantenedor diretamente.

Ao relatar, inclua uma descrição do impacto, passos mínimos para reproduzir e
qualquer mitigação já conhecida. O projeto confirmará o recebimento e
acompanhará a correção antes de uma divulgação pública.
